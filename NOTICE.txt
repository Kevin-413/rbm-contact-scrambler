This plugin's obfuscation approach (the "eScrambler Scramble Stack") is
custom, original code written for this plugin: split -> rotate -> XOR ->
Base64 encode -> shuffle -> rebuild. It is intentionally lightweight
client-side obfuscation, not encryption or secure storage - publicly
displayed contact information can still be recovered by a determined
visitor or automated browser.

No third-party libraries, frameworks, or code are bundled with this plugin.
